## Muvyo 能做什么

把网盘变成私人媒体库：找片、转存、整理、播放在一个容器里完成。

- **想看什么搜一下，剩下的它自动追**：搜片名就能看到各个来源的资源，挑一个转存进网盘；剧集订阅后，更新了自己找、自己存。
- **乱七八糟的文件，自动变成能播的媒体库**：新文件进来，自动识别、改名、归类、刮削并生成 STRM，进海报墙就能播。
- **自带媒体库和播放器**：内置媒体服务 Vyo，打开网页就能看；Infuse、Emby、Jellyfin、Plex 也都能接。
- **云盘里的文件，像本地文件一样打开**：网盘挂成本机目录，还能开 WebDAV 给 Infuse、nPlayer 用。
- **一个人搭好，全家一起用**：给家人各开账号，想看什么自己提，你点通过就自动入库。
- **用一句话改设置**：在网页、Telegram 或企业微信里说一句，搜片、订阅、改配置都行，改动要你点确认。

还有弹幕、片头片尾跳过、ISO 原盘网页播放、缺字幕自动补齐、有声书库、订阅日历、从 Emby / Jellyfin 搬家……完整功能见 [官网](https://muvyo.com/)。

## 三步开始

1. **安装并打开**：用 Docker 镜像 `thsrite/muvyo` 启动（支持 amd64 / arm64），照 [部署说明](https://muvyo.com/docs.html#deploy) 激活，向导会一步步带你配置。
2. **连接你的服务**：添加常用网盘，确认默认转存目录。
3. **开始整理与播放**：整理并生成 STRM，加入 Vyo，打开海报墙就能看。

可以先领试用码免费试用，跑通了再赞助换永久授权，详见 [官网](https://muvyo.com/)。
